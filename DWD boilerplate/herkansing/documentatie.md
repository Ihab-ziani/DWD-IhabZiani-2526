# Documentatie AI Opgave - Personagezoeker

## Initiele prompt
> Maak een single page applicatie "Personagezoeker" met de Rick and Morty API. Zoek op naam, toon kaarten met naam, afbeelding, status, soort. Klik voor details (modal) met herkomst, locatie, afleveringen. Favorieten met hartje, opslag in localStorage. Foutafhandeling. Enkel vanilla HTML/CSS/JS, async/await, responsive.

## Plan van aanpak (door AI gegenereerd)
1. HTML structuur: zoekbalk, grid, modal
2. CSS: responsive design, kaarten, hartjes, badges
3. JavaScript: fetch API, localStorage, event delegation

## Gebruikte agents
- Claude (via chat interface)
- ChatGPT (voor prompt optimalisatie)
- Geen andere agents

## Gespreksverloop (bondig)
1. **Stap 1** – Basis HTML/CSS/JS gegenereerd met zoekfunctie
2. **Stap 2** – Favorieten toegevoegd met localStorage
3. **Stap 3** – Modal voor details (afleveringen, locatie)
4. **Stap 4** – Foutafhandeling en meldingen toegevoegd
5. **Stap 5** – Responsive verbeterd en styling afgewerkt
