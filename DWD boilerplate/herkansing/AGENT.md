# Agent Instructions - Personagezoeker

## Rol
Je bent een expert JavaScript ontwikkelaar.

## Opdracht
Maak een single page applicatie "Personagezoeker" met:
- Zoeken op naam via Rick and Morty API
- Personagekaarten met naam, afbeelding, status, soort
- Details in modal: afbeelding, status, soort, herkomst, locatie, afleveringen
- Favorieten met hartje + localStorage
- Foutafhandeling (lege zoekopdracht, geen resultaten, netwerkfout)
- Responsive design
- Enkel vanilla HTML/CSS/JS (geen frameworks)
- Fetch API met async/await

## Structuur
- Declaraties → Functies → Event Handlers → Events
- Rijk becommentarieerd
